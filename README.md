# Transparent-Conductors-Predictions
**John El Berch**

***
## About
The following repository contains a model for predicting __formation energies__ and __bandgap energies__ of promising transparent semiconductors, based on Aluminum, Gallium and Indium alloys. The original data was obtained from the __Nomad2018 Predicting Transparent Conductors__ competition, featured on Kaggle and available on the following [__Link__](https://www.kaggle.com/competitions/nomad2018-predict-transparent-conductors/rules).

This model was featured as a class project for for the __applied predictive modeling__ (CMPINF2120) class, Spring 2023, at the University of Pittsburgh.


***
## About the data
The data is split in a training and a test set.
